# Authentication preview
Requires configured SMTP with STARTTLS and a strong unique PostgreSQL password. Public registration grants customer only. Admin role assignment is not exposed. Email codes are stored as hashes. Cookie sessions expire after eight hours. Origin checks and coarse Redis rate limiting are present. This is not production-ready: integration tests, per-account throttling, SMTP failure handling, audit logs, MFA, token cleanup and security review remain pending. Do not expose public registration until reviewed. Automated deployment is intentionally blocked because the old image-only rollback cannot safely handle schema changes. Use reviewed manual migrations, database backups and a separate staging environment. No live execution.
