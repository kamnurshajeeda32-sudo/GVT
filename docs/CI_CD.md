# Preview CI/CD
CI runs on develop/main pushes and PRs. Deployment is manually dispatched from develop, rebuilds and tests ARM64 images, then transfers them over SSH. Configure environment grtalgo-preview with required reviewers and develop-only deployment branch policy before adding secrets. Secrets: GRT_HOST, GRT_USER, GRT_SSH_KEY, GRT_KNOWN_HOSTS. Install reviewed scripts/deploy-preview.sh as a root-owned executable /usr/local/sbin/grtalgo-deploy-preview and restrict the dedicated SSH key to that forced command with restrict. Docker access is root-equivalent; use a dedicated VM for stronger isolation. Current rollout changes images only, not compose or database schemas. Do not use this pipeline for database migrations or live trading. No GNK resources are targeted. Main has no workflow yet: GitHub requires workflow_dispatch workflow on default branch; merge reviewed workflow to main before dispatch.
